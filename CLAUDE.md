# RCam

macOS menu-bar RTSP camera viewer (app + camera-extension system extension + `rcamcli`).

## Building and running

- `scripts/build.sh` is the canonical build: it stamps `CFBundleVersion`, runs `xcodegen generate`, builds the RCam and rcamcli schemes, and installs the app to `/Applications/RCam.app`. A bare `xcodebuild` compiles but does **not** update the installed app — to see a change in the running app, run `scripts/build.sh` and relaunch RCam.
- The project file is generated by XcodeGen from `project.yml`; edit `project.yml`, not `RCam.xcodeproj`.
- `scripts/build-ffmpeg.sh` rebuilds the vendored FFmpeg in `vendor/`; `scripts/testrig.sh start` spins up a local RTSP test rig (mediamtx + synthetic streams at `rtsp://127.0.0.1:8554/test` and `/test-sub`).
